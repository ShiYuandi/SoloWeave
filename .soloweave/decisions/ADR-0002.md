# ADR-0002：Skills 优先与 Go CLI 渐进退出

日期：2026-10-10

状态：开发者在本轮对话中确认实施。

## 背景

ADR-0001 记录了 V0.1 以 Go CLI 为中心的实现。开发者现在希望 SoloWeave 以可直接安装、由 AI 自主使用的 Skills 为主体，减少用户每次开发前的命令步骤，并逐步移除 Go。

## 决定

1. 仓库根目录 `skills/` 是新版 Skill 的维护与发布来源。默认使用路径是安装 Skills 后正常提出开发需求，由 Agent 按任务选择工作流并维护项目上下文。
2. 现有 Go CLI 与 `internal/bundle/assets/skills/` 暂作为已发布 v0.1.1-preview 的旧版实现保留，避免立即破坏已有使用者。新版 Skill 不依赖 Go CLI。
3. 纯 Skills 验收完成后，另行决定 Go CLI 的停更、迁出或删除；不在本次迁移中直接删除代码或用户数据。
4. `.soloweave/project.yaml` 和 `approval.json` 继续描述旧版 Go CLI 子工程，暂不手工改写其机器批准状态。SoloWeave 整体的新产品方向以本 ADR、`docs/skills-first-design.md` 和项目介绍为准。

## 取舍

迁移期保留两套目录，但仅根目录 `skills/` 接受新版 Skill 内容改动。旧版 CLI 不会自动获得新流程；文档与发布页必须明确版本边界。自动选择 Skill 仍需在真实客户端验证，不能承诺百分之百触发。

本决定取代 ADR-0001 关于 SoloWeave **整体产品以 Go CLI 为中心**的方向；ADR-0001 对保留的旧版 Go 子工程仍有效。
