# ADR-0003：移除 Go CLI，收敛为纯 Skills

日期：2026-10-11。状态：已确认；开发者审阅八阶段退出计划后明确要求实施。

## 背景与决定

新版六个 Skill 已不依赖 CLI。迁移期保留的 Go 实现、旧内置 Skills 和程序发布链增加了维护负担，并让使用文档出现两套入口。

本仓库停止维护并移除 Go CLI 源码与构建链，保留根目录 `skills/` 作为唯一 Skill 来源。维护者通过 PowerShell 7 脚本执行校验和打包；普通用户只安装 Skills。保留已发布 CLI 的历史版本，不创建替代应用框架或强制用户安装新的程序。

Markdown 项目资料与 ADR 继续生效；本仓库旧 `project.yaml`、`approval.json`、`checkpoint.json` 保存为明确标记的历史资料。迁移指南要求核对既有项目决定，不能把旧批准状态直接套到新方案，也不自动删除其他项目的机器文件或安装目录。

## 取舍与验收

纯 Skills 不再提供 CLI 的结构化校验、安装清单或机器过期检测；Agent 负责读取、核对并更新项目记录，不能声称这些机器检查已运行。发布前以轻量脚本和真实客户端证据验收。未实测平台单独标注，不保证自动调用总会发生。

本决定取代 ADR-0002 中暂时保留 Go 子工程的安排，以及 ADR-0001 对该子工程的当前约束；两个旧 ADR 作为历史保留。提交、推送和公开发布仍遵守 AGENTS.md。
