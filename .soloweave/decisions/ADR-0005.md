# ADR-0005：恢复五个 Skill，移除独立故障排查

- 日期：2026-10-11
- 状态：开发者已确认

## 背景与决定

开发者明确认为 SoloWeave 不需要故障排查能力，要求先评估对其他 Skill 的影响，再决定移除；审阅依赖分析后回复“可以 开始吧”。

恢复开发入口、项目设置、功能开发、质量检查、项目交接五项。删除 systematic-debugging 及其路由，不把复现、定位原因和回归修复的专门流程移入其他 Skill。功能开发保留相关验证、真实失败和阻塞记录；质量检查保留有依据的问题报告；交接不以查明根因为前提。AI 自身处理普通代码修改的能力不由 SoloWeave 禁止。

## 影响与验证

只有入口直接引用被移除的 Skill；其余四项不依赖它。入口和功能开发有内容变化，分别升级至 0.2.4，其他三项版本不变。维护脚本按五项校验，行为夹具改为五项独立加全套路由与受阻交接，共七项。双语公开文档同步；旧六项结果和原始证据保留并标明版本边界。

本地实施不授权提交、推送、SkillHub 修改或用户全局卸载；现有线上条目和用户已安装文件不会自动消失。验收结果见 docs/agent-acceptance.md。
