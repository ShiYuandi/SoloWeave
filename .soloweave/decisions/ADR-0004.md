# ADR-0004：统一为 Skills 项目文档

日期：2026-10-11。状态：开发者已确认。

## 决定

开发者明确要求将 SoloWeave 按新的纯 Skills 仓库整理。当前设计以 `docs/design.md` 为准，实施与后续任务写在 `docs/development-plan.md`。

仓库仅维护六个可独立安装的 Skill、必要参考资料、维护脚本和实际验收证据。删除不再适用的产品设计、配置归档、迁移文档和架构记录；中英文公开说明只介绍当前产品。

## 约束

保留真实客户端测试结果及其版本、模型和场景边界，不改写原始证据。项目记录保持可交接，Skill 内容和版本不因本次文档整理改变。提交、推送和线上发布继续遵循 AGENTS.md 的明确授权规则。
