# 项目连续性

[English](en/project-continuity.md)

项目上下文保存在项目文件中。优先复用已有文档；默认记录位置见[项目记录与决策](configuration.md)。

完成重要任务、遇到阻塞或准备切换账号时，Agent 应更新状态和交接，至少留下当前任务、最近修改与文件、实际验证命令和结果、未解决事项、下一步、核对时间及可取得的 Git 状态。

把验证区分为通过、失败、未运行和工具不可用。构建受权限阻止就记录权限阻止；不能推断实际构建结果。没有 Git 就写“Git 不可用”。不把凭据或令牌放进记录。

新会话收到“请继续这个项目”时，先读目标、状态、交接和相关 ADR，再核对源码与 Git。有明确下一步时先推进已知工作；只有关键决定或目标确实缺失时再询问。交接过期时说明差异，以当前文件为准。

Skills 维护 Markdown 记录，接手时需核对文件与实际验证结果。详细使用见[Skills 工作流](skill-only-workflow.md)。
