# SoloWeave 开发计划

核对日期：2026-10-11。当前定位：面向个人开发者与 1–5 人团队的 AI 开发 Skills。

## 已完成：统一项目文档

开发者要求按新的纯 Skills 仓库整理，不再保留已取消产品方案的使用说明、迁移路径和配置归档。

1. 将当前 Skills 设计整理为 `docs/design.md`，统一设计与计划入口。
2. 删除过时设计、迁移计划、配置归档及不再适用的架构记录；保留 Skills 实际回测报告与原始证据。
3. 同步中文与英文 README、贡献、目录、使用、验收及发布说明；变更记录只描述当前产品。
4. 更新 AGENTS.md、项目介绍、状态和交接记录，避免后续 Agent 沿用失效路径。
5. 运行文档相对链接检查、Skill 资源检查及 Git 空白检查，审阅最终差异。

验收：公开说明只有 Skills 安装和使用入口；文档链接有效；六个 Skill 的内容和版本保持一致；真实测试结果及尚未验证的客户端有明确记录。文档整理与 README 痛点修订已按明确授权推送；README 六项 Skill 的用途、介入时机和协作示例也已补齐，本轮按开发者指令提交推送。

## 当前交付基础

- 已完成 15 项维护检查、12 个真实 Codex 会话和公开 GitHub 安装文件核对；范围见 [验收记录](agent-acceptance.md)。
- 六项 SkillHub 审核已提交；当时状态见 [交付记录](release-status.md)，实时结果以平台为准。

## 后续计划（按优先级）

以下是下一阶段计划，不代表已经执行；本轮仅提交 README 与计划文档。

| 顺序 | 工作 | 完成标准 |
| --- | --- | --- |
| 1 | 核对 SkillHub 六项审核、中文名称与概述、正文和公开下载。 | 逐项记录实际状态；已发布包的版本、SKILL.md 和参考资料与 GitHub 源码一致，待审核项继续标明待审核。 |
| 2 | 补足现有验收未覆盖的场景。 | 优先验证已有项目接入、用户修改过的安装文件、混合项目类型；再覆盖移动端、桌面端、CLI／自动化、数据／AI。保留普通原始请求和实际证据，不重复已通过的相同场景凑数量。 |
| 3 | 在可用环境补测 Claude Code 的 Anthropic 模型与 Cursor。 | 分开记录客户端、模型、Skill 版本和实际调用；覆盖选型确认、代码复用、受阻交接和新会话恢复。不可用时明确待测，不阻塞其他独立工作。 |
| 4 | 根据真实失败案例修订 Skill。 | 只针对可观察问题修改，重跑相关失败场景及受影响检查；有内容变化才更新对应 Skill 版本，同步双语文档。参考示例不限制 AI 选型。 |
| 5 | 整理首个稳定的整套 Skills 发布快照。 | 汇总六项版本、安装方式、适用场景、实测范围与限制，备好六包和校验和；开发者明确要求后创建 GitHub Release 并同步 SkillHub。 |

优先完成平台内容一致性和已有项目体验，再根据证据调整规则。提交、推送和公开发布按 AGENTS.md 取得明确指令。
