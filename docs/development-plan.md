# SoloWeave 开发计划

核对日期：2026-10-11。当前定位：面向个人开发者与 1–5 人团队的 AI 开发 Skills。

## 本轮：统一项目文档

开发者要求按新的纯 Skills 仓库整理，不再保留已取消产品方案的使用说明、迁移路径和配置归档。

1. 将当前 Skills 设计整理为 `docs/design.md`，统一设计与计划入口。
2. 删除过时设计、迁移计划、配置归档及不再适用的架构记录；保留 Skills 实际回测报告与原始证据。
3. 同步中文与英文 README、贡献、目录、使用、验收及发布说明；变更记录只描述当前产品。
4. 更新 AGENTS.md、项目介绍、状态和交接记录，避免后续 Agent 沿用失效路径。
5. 运行文档相对链接检查、Skill 资源检查及 Git 空白检查，审阅最终差异。

验收：公开说明只有 Skills 安装和使用入口；文档链接有效；六个 Skill 的内容和版本保持一致；真实测试结果及尚未验证的客户端有明确记录。本轮只整理工作区文档，提交、推送和线上发布按开发者的后续明确指令执行。

## 当前交付基础

- 根目录 `skills/` 提供六个可独立安装的 Skill，参考资料随完整目录安装。
- PowerShell 7 维护脚本执行元数据、文档与打包检查；GitHub CI 使用相同脚本。
- 已完成 15 项维护检查、12 个真实 Codex 会话和公开 GitHub 安装文件核对；范围见 [验收记录](agent-acceptance.md)。
- 六项 SkillHub 审核已提交；当时状态见 [交付记录](release-status.md)，实时结果以平台为准。

## 后续计划

1. 核对 SkillHub 审核结果、中文概述和公开下载内容。
2. 在可用环境测试 Claude Code 的 Anthropic 模型及 Cursor；与已有 glm-5.3 和 Codex 结果分开记录。
3. 扩展移动端、桌面端、CLI／自动化和数据／AI 场景，补充混合类型、已有项目与文件冲突验收。
4. 根据真实失败案例完善触发、选型、复用、调试和交接规则；示例不限制 AI 推荐的技术。
5. 按 [发布指南](releasing.md)维护 GitHub 与 SkillHub，版本变更须有对应内容和验证依据。
