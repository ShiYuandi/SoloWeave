# 纯 Skills 与 Go CLI 退出实施计划

日期：2026-10-11。开发者审阅八阶段计划后明确要求“你做吧”。决定见 [ADR-0003](../.soloweave/decisions/ADR-0003.md)。

## 目标与授权范围

交付六个可独立安装的 Skills、参考资料、双语文档和维护者的轻量校验打包脚本；当前源码、CI 和用户使用流程不再依赖 Go。保留已发布 CLI 的历史下载及迁移说明，不删除其他项目的文件。本轮实施当前工作目录，保留原有未提交改动；提交、推送和公开发布仍须按 AGENTS.md 取得单独明确指令。

## 实施顺序

1. 整理既有修订与 Claude Code CLI 回测；保留实际模型 `glm-5.3` 的边界。
2. 在隔离目录尝试真实 Codex 新会话回测；无法启动或访问服务时记录阻塞，不以人工演练代替客户端验收。
3. 检查六个 Skill 可独立使用；按真实问题调整规则，不强制所有 Skill 每次都被调用。
4. 建立不依赖 Go 的格式、引用、打包、校验和检查及负例测试；CI 使用同一套脚本。
5. 写明旧 CLI 停更与项目记录迁移步骤；保存本仓库的旧机器记录为历史资料。
6. 移除 `cmd/`、`internal/`、`go.mod`、`go.sum`、Go 构建脚本和 CLI 发布工作流。核对绝对路径后清理本地 Go 工具链及 CLI 构建产物。
7. 同步中英文 README、贡献、配置、交接、目录和发布指南；历史设计明确标为归档。
8. 校验六包内容与源码、安装产物和全部当前文档链接，记录真实结果；准备 GitHub/SkillHub 发布清单，在线更新待单独授权。

## 验收与限制

- 不安装 Go 也能检查、打包并安装六个 Skill；缺失字段、缺失引用、非法版本和用户文件冲突不能被静默忽略。
- 保留 Markdown 上下文和 ADR；纯 Skills 不创建机器批准或检查点记录。
- 未取得真实客户端结果的场景保持待验证。Cursor、Anthropic 模型和跨平台实机不是本轮移除 Go 的前置门槛。
- 独立 Skill 的静态检查、安装核对与真实行为分别记录，不能互相替代。
