# Security

[简体中文（主版本）](../../SECURITY.md)

Do not put real credentials, tokens, passwords, or private keys in `.soloweave/` documents, test fixtures, issues, or logs. The installer should protect existing user files and reject paths outside the selected project.

For a security concern, contact the project maintainer privately before disclosing details in a public issue. A formal reporting channel has not yet been published; this document will be updated when one is available.
